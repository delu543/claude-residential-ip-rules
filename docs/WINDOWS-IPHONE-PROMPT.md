# 可直接发给目标 Windows 电脑上的 Codex

复制下面整段；在目标 Windows 本地 Codex 执行，不能只用无本地工具的云端对话：

> 请读取并在本机执行这个仓库的最新版本：https://github.com/delu543/claude-residential-ip-rules 。这是 Windows 电脑，浏览器为 Chrome，手机是通过数据线连接的 iPhone，使用 Shadowrocket。先读 AGENTS.md、docs/WINDOWS-IPHONE.md 和其中关联的实施说明。我授权你检查本机现有配置、保留备份后实施本仓库的分流与客户端/浏览器配置，并完成验证；依赖先检查复用，缺失时只从官方渠道安装到独立环境，系统信任、UAC、VPN等必须由我确认的弹窗再提示我。请按两阶段连续执行：第一阶段先检查昨天遗留的真实状态和已有回执，只修未完成或漂移的部分，不盲目重跑。先保证现有网络和 Codex 可用，再配置 Clash Verge 的两订阅分流、Claude Desktop及已安装的原生 Claude Code、Chrome WebRTC 防泄露，以及按本机条件验证 DNS。规则为：Claude已识别请求走单个指定住宅节点，失败拒绝、不换节点、不直连；ChatGPT、Codex及其他外网走普通订阅，美国优先，失败可换其他普通地区，但不得使用住宅；国内/局域网直连。所有订阅角色、节点、端口、出口IP、程序路径和版本从这台电脑读取并核实，不复制作者参数；无法确定套餐角色或固定出口时再向我确认。保持健康联网方式，不为安装先启用 TUN，不改时区、不关闭安全软件、不终止开发任务。若需要从系统代理试验 TUN，先说明短时影响并取得本机测试许可，使用独立恢复进程；试验失败恢复工作网络，不把未通过的DNS当完成。运行 windows_setup.py check，核对浏览器有效政策及真实客户端连接，保存回退方法和证据。第二阶段使用 windows_phone.py doctor/devices/pair/probe 检查 Windows Apple 设备服务、数据线、信任和手机真实版本；只操作选定 iPhone 的 Shadowrocket Documents，不开热点、不读取完整手机备份。电脑检查通过后，用手机自己的普通/住宅订阅及原配置生成候选，备份、传入新文件并读回校验，再通过小火箭正式界面导入、编译、选择配置模式和实际 STUN 防护，验证住宅/普通/国内路由、DNS/WebRTC及故障恢复。手机未连接时先完成电脑阶段并保留进度，之后接线继续；手机失败不得破坏已完成的电脑网络。只在真正需要系统确认、缺输入或没有手机界面操作能力时提示我完成必要动作，不把传输成功当作手机配置完成。不得上传订阅密钥、使用在线订阅转换器、保证不封号或把CI结果当实机证据。最后逐项说明电脑与手机哪些已通过、哪些还缺实测，以及如何恢复。
