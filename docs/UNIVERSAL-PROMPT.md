# 通用完整提示词

在要配置的设备所对应的**本地 Codex**发送下面整段。可同时配置电脑及连接的手机，但不得默认手机类型、代理 App 或订阅数量。没有设备工具的云端会话只能准备方案，不能声称已操作设备。

```text
请读取并按我的真实环境实施这个仓库的最新版：
https://github.com/delu543/claude-residential-ip-rules

先读 AGENTS.md、docs/UNIVERSAL.md、docs/LEAK-PROTECTION.md 和对应平台/客户端说明。我授权你检查并配置本机，以及我明确指定、已连接的手机；先识别设备、操作系统、代理客户端与内核、实际版本、浏览器、现有联网方式、当前规则和已安装的 Claude 入口。不得预设 Windows/Mac、iPhone/Android、Clash Verge/Shadowrocket，也不得假设每个人恰好有两份订阅。不要修改其他正常设备。

先执行只读环境盘点。软件、依赖和权限不足时，复用兼容安装，只从核实的官方来源自动补齐当前步骤必要且已授权的缺项，尽量使用独立环境，安装后复查并继续。不要只给安装清单就结束。不要批量升级、重装正常内核/驱动、自动重启、付费、退出开发应用或先打开 TUN。系统 UAC、手机信任/VPN、登录/购买、设备选择、无法推断的套餐用途或无法代操作的界面，再请我完成最少必要动作；保存进度并在确认后复查续接。不得绕过组织政策、系统权限或 App 私有数据隔离。

使用 universal.py discover 盘点，并根据实际客户端选择适配器。把实际导出/本地缓存的任意数量节点来源放在本地私有清单中，以来源ID+节点身份选路，避免同名混淆。不能从节点名称猜住宅、独享、国家或计费角色。能从现有配置、已授权信息或隔离观测确定的先自行确认；不能确定的关键角色、固定出口和普通节点范围，再集中问我。没有来源时保留当前网络，说明所缺的原生导出或订阅，不自动购买。不同设备各用自己的清单，不复制作者或另一台设备的节点、账号、路径、IP、端口。

分流原则：Claude 已识别域名、受支持的客户端和专用代理入口，固定到我确认的一个节点；失败就请求失败，不自动换节点，不直连。该节点可以是我购买的住宅线路，也可以是我明确指定的其他代理，不能把“住宅”当必需套餐或质量保证。ChatGPT、Codex、Twitter、YouTube 等普通外网只用获准的普通池，可合并多份来源，默认美国优先、其他普通地区备用，绝不借 Claude 专线。国内和局域网按所在地区、已有规则及实际企业网络直连，不把整个浏览器或微信进程简单写死。一份订阅也可以选不同节点承担角色；专线来源不能进普通池。只有一个节点又没有普通池时说明约束，不能偷偷共用或直连，也不要应用会让当前 Codex 失联的方案。

DNS 和 WebRTC 都要落实：先审查内核DNS、节点引导、系统DNS、浏览器Secure DNS、IPv4/IPv6、TUN/VPN范围和绕过项；防止解析与代理循环，不盲目关闭加密DNS。桌面Chrome/Edge用支持的正式政策并核对浏览器有效值、真实STUN；其他浏览器先确认正式能力。手机不能套桌面注册表政策，小火箭用原生STUN控制，Surge用原生规则，实际Mihomo手机客户端按其能力选方案；如果需要拒绝UDP，先说明音视频/游戏影响并取得该项选择。不要为了测试全绿把整个浏览器或IP检测网站绑到Claude线路。DNS、WebRTC、客户端连接链和VPN关闭后的行为分别取证，不能用一个绿勾代替全部验收。

先保存本地备份、文件哈希、当前可用网络和恢复办法，再生成候选、审阅原规则/策略组/DNS/自定义功能的替换范围，运行原生语法检查和隔离的小流量测试。Mihomo候选只能交给真正兼容的内核；Surge、小火箭各用自己的原生格式，不使用在线订阅转换器。未知客户端先查官方接口和导入能力、补充对应适配及测试，不擅自改用另一款软件或把已支持客户端当全部支持。不能静默丢弃内网规则、模块、覆写、脚本或证书验证。

在已授权范围内，候选通过后继续实际部署与验证，不停在生成文件。Clash Verge走仓库现有备份/校验/应用/回滚流程，不需为了合并切换订阅卡；其他客户端走其正式本地导入/启用方式。保留当前联网，不停生产代理、不杀连接测试故障；可选TUN试验另行说明影响并先建立独立本地恢复。手机通过可用的正式USB/文件导入/界面能力完成配置：iPhone只访问受信任且已开放的Documents共享，Android不自动root或开启USB调试；缺少接口时说明具体待本人动作，不伪造权限或导入成功。手机失败不得破坏已配好的电脑网络。

验证固定出口、普通故障切换且不借专线、国内直连、实际Claude入口和下载、浏览器有效政策、DNS/STUN、手机Wi-Fi/蜂窝与IPv6、配置回读及恢复。节点失效和代理退出测试优先放在隔离实例；不把模拟、CI或USB传输说成实机完成。分流只保护进入代理的请求，若要求代理退出后任意子进程/原生手机App仍不能直连，说明需要独立隔离，不能保证本仓库已经做到。固定入口也不等于服务商出口永不改变，账号异常另走官方审核，不承诺防封号。

把每个设备的准备、安装、配置、待确认和验收状态保存在本地.private；成功步骤不重复覆盖，订阅或节点变化后重新核验，不自动扩大普通池或接受新的Claude出口。不得上传订阅、节点密钥、私有配置或设备标识。最后分别交付每台设备真实的流量路线、已验证结果、尚未实测的边界和准确回退步骤。
```
